Site web HANKA GROUP

En une phrase

Site vitrine de HANKA GROUP (Abidjan, Riviera 2) présentant ses 6 services — création d'entreprise, formation marchés publics et privés, formation certifiante, procédures administratives, immobilier, communication digitale — avec un formulaire de contact.

Ce qui a été livré

  • 4 pages : Accueil, Services, À propos, Contact.
  • Un design aux couleurs de la marque (bleu profond + doré) repris de la bannière existante, avec un logo texte « HANKA GROUP » recréé en CSS.
  • Un formulaire de contact qui ouvre la messagerie pré-remplie vers hanekatehe@gmail.com.
  • Un site adapté au mobile, à la tablette et à l'ordinateur.
  • Les bases du référencement : titres et descriptions par page, favicon, sitemap.xml, robots.txt, aperçu pour le partage sur les réseaux.
  • L'historique complet des versions sur GitHub.

Contenu provisoire à remplacer

Plusieurs textes sont marqués [Texte à valider] ou [à confirmer] : contenus rédigés pour que le site soit complet, mais à relire et corriger avec la cliente. Ils sont actuellement visibles en ligne.

  • Les textes d'accroche (accueil, à propos, descriptions des 6 services).
  • Une vraie photo (équipe, locaux, visuel de marque) pour remplacer les encadrés en pointillés.
  • Les horaires d'ouverture exacts.
  • Les 4 « atouts » et les « valeurs » de l'entreprise.
  • La liste précise des prestations de chaque service.
  • Le fichier logo officiel, si la cliente en possède un.

Comment mettre à jour le site

Le site se met à jour automatiquement : dès qu'une modification est envoyée sur GitHub, GitHub Pages republie le site en 1 à 2 minutes.

  • Textes et contenus : index.html, services.html, a-propos.html, contact.html
  • Couleurs et style : css/style.css (couleurs regroupées en haut du fichier, section :root)
git add -A
git commit -m "Description de la modification"
git push

Ou simplement : demande-moi la modification et je m'en occupe directement.

Nom de domaine personnalisé (optionnel)

  1. Acheter le nom de domaine chez un registrar (Namecheap, OVH, Gandi…).
  2. Dépôt GitHub ▸ Settings ▸ Pages ▸ Custom domain : saisir le domaine.
  3. Chez le registrar, créer les enregistrements DNS indiqués par GitHub.
  4. GitHub fournit le certificat HTTPS gratuitement une fois le domaine vérifié.

Les étapes 2 et 3 peuvent être faites pour toi une fois le domaine acheté.

Vérifier que tout fonctionne

  • Ouvrir le site sur ordinateur et sur téléphone.
  • Vérifier que les 4 pages s'affichent et que le menu fonctionne.
  • Page Contact ▸ « Envoyer ma demande » : la messagerie doit s'ouvrir pré-remplie vers hanekatehe@gmail.com.
