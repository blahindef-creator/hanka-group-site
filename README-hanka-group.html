Site web HANKA GROUP

En une phrase

Un site vitrine pour HANKA GROUP (Abidjan, Riviera 2), présentant ses 6 services (création d'entreprise, formation marchés publics et privés, formation certifiante, procédures administratives, immobilier, communication digitale), avec un formulaire de contact.

Ce qui a été livré

  • Le code source complet du site (HTML/CSS/JS), dans le dossier hanka-group-site/.
  • Un suivi de version Git local, avec un premier commit enregistrant tout le squelette du site.
  • Ce README, qui explique tout ce qu'il reste à faire pour mettre le site en ligne.

Important : le site n'est pas encore en ligne. Il faut d'abord créer un compte GitHub (étape 1), puis un compte sur l'hébergeur choisi (Netlify, étape 2), avant de pouvoir obtenir une adresse publique.

Contenu à finaliser avant la mise en ligne définitive

Beaucoup de textes du site sont volontairement marqués [Texte à valider] ou [à confirmer] — des contenus provisoires rédigés pour que le site ait une structure complète, à relire et corriger avec la cliente avant publication officielle.

  • Les textes d'accroche (accueil, à propos, descriptions détaillées des 6 services).
  • Une vraie photo (équipe, locaux, ou visuel de marque) pour remplacer les emplacements réservés.
  • Les horaires d'ouverture exacts.
  • Les 4 "atouts" / "valeurs" de l'entreprise.
  • La liste exacte des prestations pour chacun des 6 services.

Les couleurs et le logo

Reprise de l'esprit de la bannière existante (bleu profond + doré/jaune, "HANKA" en blanc, "GROUP" en doré) pour un logo texte recréé en CSS. Si un fichier logo officiel existe, il pourra remplacer ce texte stylisé à tout moment.

Étape 1 — Créer un compte GitHub (gratuit, 2 minutes)

  1. Aller sur github.com/signup et créer un compte gratuit.
  2. Cliquer sur New repository.
  3. Nom du dépôt : hanka-group-site.
  4. Ne cocher aucune case d'initialisation.
  5. Cliquer sur Create repository.
  6. Garder l'adresse affichée (https://github.com/<ton-nom>/hanka-group-site.git).

Envoyer le code sur GitHub

git remote add origin https://github.com/<ton-nom>/hanka-group-site.git
git branch -M main
git push -u origin main

Étape 2 — Mettre le site en ligne avec Netlify (gratuit)

  1. Aller sur app.netlify.com/signup et se connecter avec GitHub.
  2. Add new site ▸ Import an existing project.
  3. Choisir GitHub, autoriser l'accès, sélectionner hanka-group-site.
  4. Laisser les champs de build vides et cliquer sur Deploy.
  5. Netlify fournit une adresse du type https://hanka-group-xxxxx.netlify.app.

À chaque git push, Netlify republie automatiquement le site en 1-2 minutes.

Étape 3 — Nom de domaine personnalisé (optionnel, plus tard)

  1. Acheter un nom de domaine (Namecheap, OVH, ou via Netlify ▸ Domain settings).
  2. Dans Netlify ▸ Domain settings ▸ Add a domain, suivre les instructions DNS.
  3. Le certificat HTTPS est fourni gratuitement une fois le domaine connecté.

Sauvegardes et historique des versions

Chaque étape importante est enregistrée comme un "commit" Git — un point de sauvegarde. Une fois le dépôt poussé sur GitHub, l'historique complet sera visible dans l'onglet Commits du dépôt.

Comment mettre à jour le contenu plus tard

  • Textes et services : index.html, services.html, a-propos.html, contact.html.
  • Couleurs et style : css/style.css (variables en haut du fichier, section :root).
  • Après modification : git add -A, git commit -m "...", git push.
